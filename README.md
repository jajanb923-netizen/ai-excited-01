# ai-excited-01 entry: a whale in a teacup

A colossal blue whale breaches out of a tiny porcelain teacup on a
wooden kitchen table, a towering column of sparkling water exploding
upward around it while a miniature sailboat rides the crest of the
wave. Warm morning light pours through the kitchen window and catches
the spray — deep teal and sapphire against warm amber wood and creamy
porcelain. One impossible scale twist, one clear focal point, no text.

The program writes this one picture to `/output/entry.png`. `main.ts`
is Node 22, standard library only, and copies `entry.png` to the
output directory after checking its magic bytes, its size and its
dimensions. `entry.png` is a 1024 by 1024 pixel JPEG of about
302 kilobytes.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
